# ⚖️ JURIS GESTIÓN PRO

**Sistema de gestión jurídica para Honduras.**

Herramienta profesional para abogados, fiscales y gestores jurídicos.

## ✨ Características
- Gestión de expedientes y casos
- Control de fechas y vencimientos
- Reportes jurídicos
- Compatible con Windows 10/11

## 📥 Descarga
Ve a la sección [Releases](../../releases) y descarga el instalador `.exe`.
